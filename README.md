# Financial-Statements

Aplikasi pencatatan keuangan pribadi — Neraca, Transaksi (Pemasukan/Pengeluaran/Transfer), Wallet multi-sumber dana, dan tracking Utang dengan kalkulasi bunga otomatis. Dibangun buat trial and error pribadi, prinsip akuntansi + Kiyosaki.

## Fitur
- Dashboard ringkasan total kekayaan bersih
- Transaksi: Pemasukan, Pengeluaran, Transfer antar wallet
- Wallet: lacak saldo per sumber dana (Cash/Bank/E-Wallet/RDN)
- Utang: kalkulasi otomatis bunga & biaya riil dari pinjaman
- Neraca: harta dengan status Aset/Netral otomatis (untuk barang yang dipakai kerja)

## Cara pakai
Buka `index.html` langsung di browser, atau akses lewat GitHub Pages. Bisa di-"Add to Home Screen" di HP untuk pengalaman seperti aplikasi native.

Data tersimpan lokal di browser (localStorage) — tidak terkirim ke server manapun.
